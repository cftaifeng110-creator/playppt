# 翻页助手 PresenterGuard

一款原生 macOS 菜单栏／窗口应用，用于在 **WPS 演示扩展屏放映**时识别 USB 或蓝牙翻页笔，把翻页指令定向发送给 WPS，同时尽量避免影响你在主屏使用其他软件。

## 功能

- 自动发现 USB 接收器、蓝牙及其他 HID 演示设备。
- 根据设备名称识别常见 Presenter／Clicker／Remote，也可手动选择通用 HID 设备。
- 支持常见按键：Page Down、Page Up、方向键、空格、回车、B、W、F5、Esc，以及部分 Consumer Control／Button 接口。
- 将指令直接发送到 WPS 进程；直接转发无效时，可开启 WPS 兼容模式。
- 拦截已选翻页笔产生的原始键盘事件，避免方向键、空格等同时作用于当前软件。
- 普通鼠标不拦截；普通键盘仅在匹配到已选翻页笔的 HID 事件时过滤对应按键。
- 显示 WPS、扩展屏和翻页笔状态，提供本地事件记录。
- 支持菜单栏快捷控制、暂停守护和登录后启动。

## 系统要求

- macOS 13 Ventura 或更高版本。
- Apple Silicon 或 Intel Mac。
- WPS Office for Mac。
- 用于本地构建：Xcode 15 或更高版本。

## 在 Mac 上生成安装包

1. 解压完整工程，并安装 Xcode。

2. 在工程根目录打开“终端”，执行：

   ```bash
   zsh Scripts/build_dmg.sh
   ```

3. 构建完成后，安装包位于：

   ```text
   dist/翻页助手-1.0.0.dmg
   ```

4. 打开 DMG，将“翻页助手”拖入 Applications。

脚本默认进行本地 ad-hoc 签名，适合自己构建、自己使用。若要公开分发，应使用 Developer ID 签名并经过 Apple 公证。

## 使用步骤

1. 连接扩展显示器或投影仪，并在 macOS 中设置为“扩展显示器”模式。
2. 打开翻页助手，进入“设置 → 权限”，允许“输入监听”和“辅助功能”。前者用于识别输入，后者用于过滤原始按键并发送演示指令。
3. 插入 USB 接收器或连接蓝牙翻页笔，在“翻页笔”页面确认设备已被选择。
4. 在 WPS 中打开 PPT，开始放映，并把放映窗口放在扩展屏。
5. 点击“开启守护”，然后回到主屏正常使用其他软件。
6. 按翻页笔测试上一页、下一页。事件记录会显示“设备 → WPS：动作”。

## 兼容问题排查

### 翻页笔没有出现在列表中

- 重新插拔 USB 接收器，或断开并重新连接蓝牙。
- 检查 macOS“系统设置 → 隐私与安全性 → 输入监听”中是否允许翻页助手。
- 某些纯鼠标式翻页笔使用厂商私有协议，本版本只处理标准键盘、Consumer Control 和 Button HID 接口。

### 能识别按键，但 WPS 不翻页

- 确认 WPS 已进入放映状态，而不只是打开 PPT 编辑页面。
- 在“设置”中开启 **WPS 兼容模式**，并允许“辅助功能”权限。该模式会短暂切换焦点，再恢复之前使用的软件。
- 不同 WPS 版本对后台进程事件的接收行为可能不同，因此首选直接转发，必要时才使用兼容模式。

### 当前软件仍受到翻页笔原始按键影响

- 保持“拦截已选翻页笔产生的原始按键”开启。
- 保持“优先尝试独占已选翻页笔”开启。独占不可用时，应用会回退到 HID 与系统按键的短时匹配。
- 如果某支翻页笔绕过 HID 值回调，可把它的产品名、厂商 ID、产品 ID 和事件记录用于后续适配。

### 内置键盘或其他设备被误选

在“翻页笔”页面取消选择。应用不会自动选择内置键盘，也不会把鼠标移动纳入拦截。

## 隐私与安全

- 不联网，不上传输入数据。
- 不读取或记录正常键盘输入的内容；事件记录只保存到内存，包含设备名、演示动作和运行状态。
- 全局按键过滤仅用于匹配已选翻页笔；未匹配事件立即放行。

## 工程结构

- `PresenterGuard/Models`：设备、按键映射和应用状态。
- `PresenterGuard/Services`：HID 发现、按键过滤、权限和 WPS 定向发送。
- `PresenterGuard/Views`：SwiftUI 主界面。
- `PresenterGuard/Resources`：应用图标与颜色资源。
- `Scripts/build_dmg.sh`：Release 构建、签名、验证和 DMG 打包。

> 本工程未附带预编译安装包。需要在 macOS 上完成最终编译，并用你的实际 WPS 版本和翻页笔进行硬件联调。
